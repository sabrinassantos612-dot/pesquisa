# Pesquisa de Satisfação de Clientes - TudoWeb

O programa solicita dados como nome, idade e a nota de avaliação do cliente, valida os dados e conta quantas avaliações foram Excelentes ou Ruins.

# Funcionalidades

- Coleta de Dados:Registra nome e idade de cada entrevistado.
- Validação de Entrada:Utiliza a estrutura de repetição `while` para garantir que o usuário digite apenas opções válidas (1, 2 ou 3).
- Exibição de Resultados:Apresenta o resultado final com o total de respostas "Excelente" e "Ruim".

# Tecnologias Utilizadas

- Python 
- Visual Studio Code
- Git & GitHub

# Como Utilizar o Programa

1. Abra o terminal no VS Code 
2. Navega até a pasta do projeto

#  Quando o programa iniciar, ele vai pedir as informações de cada entrevistado em sequência:
- Nome: Digita o nome do cliente 
- Idade: Digita a idade (apenas números) 
- nota de Avaliação: Escolha uma das opções do menu:1,2 ou 3 
  
# Nota: Se digitares qualquer outro número, o programa vai avisar que a opção é inválida e pedir para digitares novamente.

Após responderes a todos os entrevistados, o programa exibe automaticamente o resumo final com a contagem total das respostas.
